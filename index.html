Flutter 레이아웃을 위한 EdgeInsets 상세 가이드

Flutter 개발 시 가장 빈번하게 사용되는 위젯 중 하나가 바로 여백을 조절하는 EdgeInsets입니다. 하지만 잘못된 패딩 값 설정은 픽셀 오버플로우(A RenderFlex overflowed) 오류의 주요 원인이 됩니다.

1. EdgeInsets의 주요 생성자 활용법

  • EdgeInsets.all(double value): 상하좌우 4방향에 동일한 패딩을 부여할 때 사용합니다. 간단한 카드 위젯 안쪽 여백에 적합합니다.
  • EdgeInsets.symmetric({vertical, horizontal}): 수평(Horizontal)과 수직(Vertical) 여백을 대칭적으로 설정할 때 유용하며, 버튼 요소나 리스트 아이템 디자인 시 자주 쓰입니다.
  • EdgeInsets.only({left, top, right, bottom}): 특정 방향에만 여백을 주어야 할 때 선택적으로 지정할 수 있어 세밀한 Layout 조정이 가능합니다.

2. 반응형 레이아웃에서의 레이아웃 깨짐 방지 팁

고정된 픽셀 단위 패딩 값을 사용하면 다양한 디바이스 화면 크기에 대응하기 어렵습니다. MediaQuery.of(context).size를 활용해 화면 비율에 맞는 가변 패딩을 적용하거나, LayoutBuilder를 조합하여 유연한 유저 인터페이스를 구성하는 것이 좋은 접근 방식입니다.

Flutter Web 배포 및 GitHub Pages 적용 가이드

Flutter는 모바일뿐만 아니라 웹 브라우저 환경까지 컴파일을 지원합니다. 작성한 코드베이스를 GitHub Pages 무료 호스팅 서버에 배포하는 과정과 주의사항을 살펴봅니다.

1. 빌드 및 Base URL 설정

GitHub Pages의 하위 경로(Repository name)에 배포할 때는 반드시 빌드 명령 시 base-href 옵션을 부여해야 리소스 경로 에러가 발생하지 않습니다.

flutter build web --base-href "/jsh_flutter_app/" 명령어를 통해 정적 리소스 파일들을 정상적으로 연결할 수 있습니다.

2. 성능 최적화 (CanvasKit vs HTML)

Flutter Web은 렌더러로 HTML과 CanvasKit을 제공합니다. 모바일 브라우저 초기로딩 속도를 우선시한다면 HTML 렌더러가 유리하고, 복잡한 그래픽 애니메이션과 폰트 렌더링의 일관성이 중요하다면 CanvasKit 렌더러 선택을 권장합니다.
