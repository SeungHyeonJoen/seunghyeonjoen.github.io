홈 Flutter 개발기 토깽이 게임 프로젝트

Flutter 웹 앱을 활용한 개발 일기와 GitHub Pages 호스팅 경험

최근 크로스 플랫폼 프레임워크인 Flutter를 활용하여 웹 애플리케이션을 제작하고, 이를 GitHub Pages에 배포하는 프로젝트를 진행했습니다. 단일 코드베이스로 모바일과 웹 환경을 동시에 지원할 수 있다는 점은 매우 큰 장점이었습니다.

1. Flutter Web 선택 이유 및 특징

Flutter는 Dart 언어를 기반으로 하며, 강력한 UI 렌더링 성능을 제공합니다. 기존 웹 개발 방식과 달리 CanvasKit이나 HTML DOM 방식을 선택하여 렌더링할 수 있어, 일관된 UI 경험을 유지하는 데 유용합니다.

2. 배포 과정에서 겪은 주요 이슈

GitHub Pages에 Flutter 웹을 배포할 때 가장 신경 써야 하는 부분은 라우팅 설정과 상대 경로 문제입니다. index.html 파일 내부의 base href 태그를 repository 이름에 맞게 수정해야 스타일이나 스크립트 리소스가 정상적으로 로드됩니다.
