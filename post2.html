홈 Flutter 개발기 토깽이 게임 프로젝트

토깽이 게임 제작 및 데이터 지속성(Highest Score) 구현 방법

간단한 미니 게임을 구현할 때 가장 중요한 요소 중 하나는 플레이어의 동기를 부여하는 '최고 기록 저장' 기능입니다. 최근 진행한 토깽이 게임 프로젝트에서의 로직 설계와 에러 해결 과정을 공유합니다.

1. 게임 종료 후 최고 기록이 사라지는 문제

개발 초기에는 최고 점수를 단순 변수(RAM)에 저장했습니다. 이 경우 게임이 종료되거나 브라우저 페이지가 새로고침되면 기록이 초기화되는 현상이 발생했습니다. 로컬 환경이나 VS Code 테스트 환경에서도 동일한 문제가 확인되었습니다.

2. LocalStorage 및 파일 저장을 활용한 해결

웹 환경에서는 Web Storage API의 localStorage를 활용하여 사용자의 브라우저에 최고 점수를 영구적으로 저장하도록 구조를 개선했습니다. 게임 종료 시 조건문을 통해 현재 점수가 최고 점수보다 높을 경우 데이터를 갱신합니다.

3. 사용자 경험(UX) 향상 방안

점수 저장 외에도 Game Over 화면에서 즉시 창이 닫히지 않고 점수를 확인할 수 있는 연출 대기 시간을 추가했습니다. 이러한 작은 디테일이 사용자의 만족도를 향상시킵니다.
